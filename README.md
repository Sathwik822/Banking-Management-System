# Pinewood Bank – Banking Management System (Java Full Stack)

| Layer | Technology |
|---|---|
| Backend | Java 17, Spring Boot 3.3, Spring Security (JWT), Spring Data JPA / Hibernate |
| Database | MySQL 8.0 |
| Frontend | React 18 (Vite), HTML, CSS, JavaScript |
| API | REST (JSON) |
| Build | Maven (backend), npm (frontend) |
| Tools | IntelliJ IDEA / Eclipse, Postman, Git & GitHub |

## Features
- Register / login with JWT authentication, BCrypt password hashing
- Roles: `CUSTOMER` and `ADMIN` (default admin is created on first start)
- Open Savings / Current accounts with auto-generated account numbers
- Deposit, withdraw, transfer between accounts (atomic, row-locked, no negative balance)
- Account statement (transaction history) with running balance
- Admin screen listing all customers and accounts

## STEP 1 – Install the tools

| Tool | Version | Check command |
|---|---|---|
| JDK | 17 (Temurin / OpenJDK) | `java -version` |
| Maven | 3.9+ (IntelliJ/Eclipse bundle one too) | `mvn -v` |
| MySQL Server + Workbench | 8.0 | `mysql --version` |
| Node.js | 18 or 20 LTS | `node -v` and `npm -v` |
| IDE | IntelliJ IDEA Community or Eclipse (Java EE) | – |
| Postman | latest | – |
| Git | latest | `git --version` |

Set `JAVA_HOME` to the JDK folder and add `%JAVA_HOME%\bin` (Windows) / `$JAVA_HOME/bin` (Mac/Linux) to `PATH`.
During MySQL install remember the **root password**.

## STEP 2 – Database
MySQL is created automatically (`createDatabaseIfNotExist=true`), but you can do it by hand:
```sql
CREATE DATABASE bankdb;
```
Open `backend/src/main/resources/application.properties` and set your MySQL password:
```
spring.datasource.username=root
spring.datasource.password=YOUR_PASSWORD
```
(or set env vars `DB_USERNAME` and `DB_PASSWORD`). Tables are generated by Hibernate (`ddl-auto=update`).

## STEP 3 – Run the backend
```bash
cd backend
mvn spring-boot:run
```
In an IDE: **File → Open** the `backend` folder (as a Maven project) → run `BankingApplication`.
API is on http://localhost:8080. First start prints: `Default admin created: admin@bank.com / Admin@123`.

## STEP 4 – Test the API in Postman
| Method | URL | Body (JSON) | Auth |
|---|---|---|---|
| POST | /api/auth/register | `{"fullName":"Asha Rao","email":"asha@mail.com","password":"secret123"}` | none |
| POST | /api/auth/login | `{"email":"asha@mail.com","password":"secret123"}` | none → copy `token` |
| POST | /api/accounts | `{"accountType":"SAVINGS","initialDeposit":5000}` | Bearer token |
| GET | /api/accounts | – | Bearer token |
| POST | /api/transactions/deposit | `{"accountNumber":"AC...","amount":1000}` | Bearer token |
| POST | /api/transactions/withdraw | `{"accountNumber":"AC...","amount":500}` | Bearer token |
| POST | /api/transactions/transfer | `{"fromAccount":"AC...","toAccount":"AC...","amount":250}` | Bearer token |
| GET | /api/accounts/{accountNumber}/transactions | – | Bearer token |
| GET | /api/admin/users | – | Bearer token of admin |
| GET | /api/admin/accounts | – | Bearer token of admin |

In Postman: **Authorization tab → Type: Bearer Token → paste token**.

## STEP 5 – Run the frontend
```bash
cd frontend
npm install
npm run dev
```
Open http://localhost:5173 → Register → open an account → deposit / withdraw / transfer.
(Keep the backend running. If the backend URL differs, copy `.env.example` to `.env`.)

```
├── backend/
│   ├── pom.xml
│   └── src/main/java/com/bank/

│       ├── security/     JwtUtil, JwtAuthFilter
│       ├── entity/       User, Account, BankTransaction   (JPA / Hibernate)
│       ├── repository/   Spring Data JPA interfaces
│       ├── dto/          request / response records
│       ├── service/      AuthService, BankService         (business logic)
│       ├── controller/   Auth, Account, Transaction, Admin (REST)
│       └── exception/    BankException, GlobalExceptionHandler
├── frontend/
│   └── src/ (App.jsx, api.js, styles.css, pages/Auth, Dashboard, Admin)
└── database/schema.sql
```

## How a request flows
React page → `api.js` (adds `Authorization: Bearer <JWT>`) → `JwtAuthFilter` validates token →
Controller → Service (`@Transactional`) → Repository → Hibernate → MySQL.

## Troubleshooting
| Problem | Fix |
|---|---|
| `Access denied for user 'root'` | Wrong MySQL password in application.properties |
| `Communications link failure` | MySQL service not running (start it) |
| `Port 8080 already in use` | Add `server.port=8081` and update `VITE_API_URL` |
| CORS error in browser | Frontend must run on http://localhost:5173 (or change `app.cors.allowed-origin`) |
| `release version 17 not supported` | Your JDK is older than 17; install JDK 17+ |
| 401 after a day | Token expired (24h) – sign in again |
